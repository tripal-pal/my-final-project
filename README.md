# 🚀 Interactive Task Manager & Portfolio Web Application

This repository contains the final web development capstone project developed as part of the web development internship program. It is a responsive, interactive single-page application built using core front-end technologies.

---

## 🔗 Live Demo
- **Live Website:** [https://tripal-pal.github.io/my-final-project/](https://tripal-pal.github.io/my-final-project/)
- **GitHub Repository:** [https://github.com/tripal-pal/my-final-project](https://github.com/tripal-pal/my-final-project)
---

## ✨ Features
- **Task Management System:** Add, manage, and track tasks dynamically using JavaScript.
- **Responsive Design:** Optimized layout for Desktop, Tablet, and Mobile devices using CSS Flexbox/Grid.
- **Asset Integration:** Properly integrated image assets and optimized styling.
- **Interactive UI:** Smooth user navigation and dynamic DOM interactions.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic structural layout.
- **CSS3:** Custom styles, animations, and responsive breakpoints.
- **JavaScript (ES6+):** Dynamic task creation and state management.
- **Git & GitHub:** Version control and GitHub Pages deployment.
